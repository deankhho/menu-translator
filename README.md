# 菜單翻譯（自建版）

拍一張日文菜單，翻成繁體中文並標註素食類別。

**線上使用**：https://deankhho.github.io/menu-translator/

## 為什麼自己做

原本用的第三方菜單翻譯網站很好用，但擔心哪天關站。查過它的實作後確認
翻譯是走站方伺服器的 API，把網頁存下來也沒用（存下來只是空殼）。
所以改成自建：**單一 HTML 檔、沒有後端**，金鑰只存在使用者自己的裝置。
就算這個 GitHub Pages 哪天不在了，把 `index.html` 存下來一樣能用。

## 使用方式

1. 開啟頁面，按「🔑 金鑰」貼上 [Google AI Studio](https://aistudio.google.com/apikey) 的 Gemini API 金鑰
   （只寫進這台裝置的 localStorage，不會送到任何第三方伺服器）
2. 填一次日圓匯率（例 0.21），台幣換算才會出現
3. 拍照或選圖 → 選飲食限制 → 按「辨識並翻譯」

手機建議加到主畫面，用起來就跟 App 一樣。

## 價格為什麼要標紅

菜單常用漢數字寫價格（「四八〇」＝480、「八〇」＝80），模型會讀錯位數。
所以價格走**兩趟獨立辨識交叉比對**：

- 綠色＝兩趟讀到同一個數字
- 紅色＝兩趟不同，兩個數字都列出來，請自己對菜單

**綠色只代表兩趟一致，不保證正確**——實測過兩趟同時把「八〇」讀成 120 的情形。
菜名和素食判斷可以信，付錢前價格還是看店內菜單。

## 實測水準

素材：Wikimedia Commons「筑前屋 お品書き」（筆文字字體、漢數字價格、傾斜拍攝、密集排版）。

- 品項召回 **25/26（96%）**，漏 1 項、1 項假名誤植
- 翻譯與素食判斷正確（`シロコロホルモン`→豬大腸圈、冷奴標「海鮮素（通常含柴魚）」）
- 端到端 34.7 秒（兩趟平行送），77 項、13 分類

## 技術

- 單檔 HTML，無框架、無後端、無建置流程
- 圖片前端縮到長邊 1600 再送（實測與原圖辨識無差異）
- 模型：`gemini-3-flash-preview`
- 假名正規化（片假名→平假名、小寫假名→大寫、去長音與空白）解決兩趟命名漂移
  造成的假警報（`バカ盛サラダ`／`バカ盛 サラダ`、`ウインナー`／`ウィンナー`）
